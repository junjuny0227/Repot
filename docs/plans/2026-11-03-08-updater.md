# Repot 계획 8: 서명된 자동 업데이트

**Goal:** 공식 Tauri updater로 새 버전을 확인하고 사용자 동의 후 설치·재시작한다. 스캔 데이터는 기기를 떠나지 않는다.

**Architecture:** core와 분리된 데스크톱 updater 서비스가 확인·보류·다운로드·설치 상태를 관리한다. UI는 시작/완료 화면에서만 업데이트를 제안한다. GitHub Releases의 서명된 자산과 `latest.json`을 사용한다.

**Tech Stack:** Tauri 2, React, TypeScript, Vitest, GitHub Actions

**Spec:** `docs/specs/2026-11-02-repot-mvp-design.md` §2·3·5·11·14

## Global Constraints

- 새 의존성: Rust `tauri-plugin-updater = "2"`, `tauri-plugin-process = "2"`; npm `@tauri-apps/plugin-updater = "2"`, `@tauri-apps/plugin-process = "2"`. 이 계획을 먼저 병합하고 추가한다. lockfile은 선언에서 재생성한다.
- core의 네트워크 금지와 프론트엔드 shell 권한 금지를 유지한다. 추가 권한은 `updater:default`, `process:allow-restart`뿐이다.
- 앱의 유일한 네트워크 기능은 GitHub 업데이트 확인/다운로드다. 자동 확인은 기본 켜짐이며 설정으로 끌 수 있다. 스캔·내보내기 데이터는 전송하지 않는다.
- 엔드포인트는 `https://github.com/junjuny0227/Repot/releases/latest/download/latest.json`. 프로덕션에서는 HTTPS만 허용한다. Windows 설치는 passive다.
- Linux의 비-AppImage 설치는 updater를 호출하지 않고 패키지 매니저/사이트 안내를 표시한다.
- updater 서명 키는 Apple 코드 서명과 별개다. 비밀 키는 `~/.tauri/repot-updater.key`, 암호는 로그인 키체인 `repot-updater-key-password`(계정 `repot`)에 보관한다. GitHub secrets는 `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. 공개 키만 커밋한다. 비밀은 출력하지 않는다.
- 릴리스는 draft, 정식 릴리스, 이름 `(beta)`를 유지한다. 이번 작업은 태그/릴리스를 만들거나 공개하지 않는다. `latest.json`은 사람이 draft를 공개한 뒤에만 latest에서 제공된다.
- 모든 새 문구는 데스크톱/사이트의 en·ko·ja·zh-Hans JSON에 둔다. AGENTS.md는 고치지 않고 권장 교체 줄만 보고한다.

## 결정과 이유

공식 updater의 서명 검증을 사용한다. 시작 시 한 번 자동 확인하고 설정의 수동 확인도 제공한다. 설정은 기존 언어 선택 옆에 둔다. 새 버전의 버전 번호·짧은 노트와 설치 및 재시작/나중에 버튼을 macOS 스타일 시트에 표시한다. 진행률과 실패 상태를 표시하며 실패 시 재시도할 수 있다. 스캔·검토·내보내기에서는 제안을 보류한다. 설치 중에는 스캔/내보내기 진입을 차단해 작업을 중단하지 않는다.

## Review Focus

1. 서명 없는/다른 키의 자산은 설치되지 않아야 한다. HTTPS 예외는 커밋하지 않은 로컬 E2E 설정에만 둔다.
2. 확인 결과가 스캔/내보내기 도중 도착해도 시작/완료까지 제안을 보류한다. 설치 중 새 작업을 시작할 수 없다.
3. 자동 확인 끔은 다음 실행에도 유지된다. 중복 확인·설치를 막고 오류가 앱의 스캔 기능을 깨지 않는다.
4. .deb/.rpm은 네트워크 updater 호출 없이 안내한다. AppImage만 Linux updater 대상이다.
5. 네 로캘의 키/자리표시자를 맞추고 노트는 HTML이 아닌 텍스트로 렌더링한다.
6. CI는 서명 secrets를 tauri-action에 전달하고 `uploadUpdaterJson: true`로 정적 manifest를 올린다. draft 공개는 사람 몫이다.
